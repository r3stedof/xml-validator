# Публикация XML Validator без написания кода

## Вариант A — Netlify (рекомендуется)

1. Откройте https://github.com/new и создайте репозиторий `xml-validator` (Public или Private).
2. На странице нового репозитория нажмите **Add file → Upload files**. Распакуйте архив проекта на компьютере и перетащите содержимое папки `xml-validator` (включая скрытую папку `.github`, если хотите CI) в окно GitHub. Нажмите **Commit changes**.
3. Откройте https://app.netlify.com/ и войдите/зарегистрируйтесь через официальный интерфейс.
4. Выберите **Add new site → Import an existing project → GitHub**, разрешите доступ к только что созданному репозиторию и выберите его.
5. Убедитесь, что команда сборки `npm run build`, а папка публикации `dist`. Файл `netlify.toml` уже задаёт эти значения.
6. Нажмите **Deploy site**. Дождитесь завершения сборки и откройте выданный Netlify HTTPS URL. Только этот адрес будет публичной ссылкой на сайт.

## Вариант B — Vercel

1. Загрузите файлы в GitHub как в шагах 1–2 выше.
2. Откройте https://vercel.com/new и войдите через официальный интерфейс.
3. Импортируйте репозиторий `xml-validator`. Используйте preset Vite, Build Command `npm run build`, Output Directory `dist`.
4. Нажмите **Deploy** и дождитесь успешного завершения. Vercel выдаст публичный HTTPS URL.

## Обновление

Загрузите новые изменения в GitHub через **Add file → Upload files** или замените изменённые файлы. После commit Netlify/Vercel автоматически пересоберёт сайт. Пароли, токены и API-ключи не нужны для приложения; не публикуйте секреты в репозитории.
